## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → FastAPI | Untrusted JSON and Origin headers cross the HTTP boundary. |
| FastAPI → SQLite | Validated request data crosses into persistent storage. |
| Host → containers | Compose configuration controls exposed ports and the writable database volume. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Tampering | Book create route/repository | high | mitigate | Use Pydantic typed bodies, SQLAlchemy bound parameters, and explicit commit/rollback; never concatenate request data into SQL. |
| T-01-02 | Denial of service | Request body and text fields | medium | mitigate | Apply bounded typed fields in the contract expansion and reject malformed payloads before persistence. |
| T-01-03 | Spoofing/Elevation | CORS middleware | medium | mitigate | Enumerate exact development origins and test Origin plus JSON preflight; do not treat CORS as authentication. |
| T-01-04 | Information disclosure | Health/error responses | medium | mitigate | Return readiness status and non-sensitive error messages without filesystem paths or tracebacks. |
| T-01-SC | Tampering | npm/PyPI installs | high | mitigate | Blocking package-legitimacy checkpoint verifies each flagged package against its official registry before installation. |
</table>
</threat_model>
